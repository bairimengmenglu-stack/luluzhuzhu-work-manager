# luluzhuzhu Work Manager

luluzhuzhu 的工作管理应用。

基于 **Electron**（Chromium + Node.js）构建，UI 布局、视觉样式与浏览器交互对齐 ZCode 桌面客户端（设计令牌与交互规格取自对其真实实现的逆向分析）。

## 功能

### 整体布局（ZCode 同款）
- **顶栏**：`titleBarStyle: hidden` + `titleBarOverlay`（透明底、原生窗口按钮、高度 44 与自绘顶栏一致），整栏可拖动、按钮 `no-drag`；左侧会话导航箭头 + 标题 + 工作区芯片
- **左侧栏**：logo、菜单（工作台 `Ctrl+1` / 浏览器 `Ctrl+2`）、项目与任务分区、底部用户区
- **主题令牌**：background `#fafafa`、sidebar `#f5f5f5`、卡片白、foreground `#404040`、边框 `rgba(10,10,10,.1)`
- **最小窗口尺寸**：480 × 640（同 ZCode）
- **整窗缩放**：`Ctrl+=` / `Ctrl+-` / `Ctrl+0`（ZCode 桌面缩放）

### 内嵌浏览器（右侧面板）
- **持久化会话**：`persist:embedded-browser` 分区 —— Cookie/登录态重启保留，代理跟随系统（同 ZCode 的 `persist:zcode-embedded-browser`）
- **多标签页**：等宽标签（最大 156px）、真实 favicon 与标题、悬停显示关闭钮、中键关闭、右键菜单（关闭标签 / 关闭其他标签 / 关闭所有标签）
- **标签总览**（∨）：搜索标签页 + 打开的标签页 + 最近关闭的标签页（可恢复），带相对时间（刚刚 / N 分钟前 / N 小时前 / N 天前）
- **新增标签**（+）：面板类型菜单（浏览器可建，终端 / 审查预留）
- **工具栏**：后退 / 前进 / 刷新（加载时旋转、历史禁用态）、地址栏（`输入网址后回车`、聚焦全选、回车导航、裸域名自动补 https）、自由尺寸、网页元素选择、更多菜单
- **自由尺寸**：可调视口宽度 × 高度（200–4096 / 200–4320 范围校验、设置持久化保存），预览缩放档位（适应窗口 / 50%–150%），实时改版页面渲染
- **网页元素选择**：悬浮高亮页面元素，点击捕获选择器，Escape 取消
- **更多菜单**：在默认浏览器中打开 / 打开调试工具
- **设置**（左下角齿轮）：忽略证书校验（仅内置浏览器分区生效）、清除内置浏览器缓存（保留 Cookie/登录态）、清除全部浏览器数据（确认弹窗，不可撤销）
- **空状态**：「粘贴或输入 URL 以打开网页。」
- **URL 校验**：仅支持 http、https、file、about、data 地址，非法输入有提示
- **错误页**：加载失败（含 HTTPS 证书不受信任的专门提示）、浏览器进程崩溃（内置浏览器启动失败 + 重试浏览器）
- **右键菜单**（宿主页面，ZCode 同款模板）：可编辑框 = 撤销/重做/剪切/复制/粘贴/删除/全选；选中文字 = 复制；未打包环境追加 Inspect Element
- 新开窗口链接在应用内新标签打开；按住 `Ctrl` 点击或 `background-tab` 交给系统浏览器；下载走系统保存对话框

## 运行

```bash
npm install
npm start
```

## 项目结构

```
src/
├── main/       # 主进程：窗口、新窗口策略、openExternal IPC
│   └── main.js
├── preload/    # 预加载：contextBridge 暴露安全 API
│   └── preload.js
└── renderer/   # 渲染进程：布局、面板切换、浏览器面板
    ├── index.html
    ├── styles.css
    └── app.js
```

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+1` | 回到工作台（收起浏览器面板） |
| `Ctrl+2` | 切换浏览器面板 |
| `Ctrl+T` | 新建浏览器标签（面板打开时） |
| `Ctrl+W` | 关闭当前标签（面板打开时） |
| `Escape` | 取消元素选择 / 关闭菜单 |
