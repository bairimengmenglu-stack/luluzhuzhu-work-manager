# luluzhuzhu Work Manager

luluzhuzhu 的工作管理应用。

基于 **Electron**（Chromium + Node.js）构建，UI 布局、视觉样式与浏览器交互对齐 ZCode 桌面客户端（设计令牌与交互规格取自对其真实实现的逆向分析）。

## 功能

### 整体布局（ZCode 同款）
- **左侧栏**：logo、菜单（工作台 `Ctrl+1` / 浏览器 `Ctrl+2`）、项目与任务分区、底部用户区
- **标题栏**：会话标题 + 工作区芯片 + 浏览器面板切换按钮（带激活态）
- **主题令牌**：background `#fafafa`、sidebar `#f5f5f5`、卡片白、foreground `#404040`、边框 `rgba(10,10,10,.1)`

### 内嵌浏览器（右侧面板）
- **多标签页**：等宽标签（最大 156px）、真实 favicon 与标题、悬停显示关闭钮、中键关闭、右键菜单（关闭标签 / 关闭其他标签 / 关闭所有标签）
- **标签总览**（∨）：打开的标签页 + 最近关闭的标签页（可恢复），带相对时间（刚刚 / N 分钟前 / N 小时前 / N 天前）
- **新增标签**（+）：面板类型菜单（浏览器可建，终端 / 审查预留）
- **工具栏**：后退 / 前进 / 刷新（加载时旋转、历史禁用态）、地址栏（`输入网址后回车`、聚焦全选、回车导航、裸域名自动补 https）、自由尺寸、网页元素选择、更多菜单
- **自由尺寸**：可调视口宽度 × 高度，实时改版页面渲染，支持适应窗口
- **网页元素选择**：悬浮高亮页面元素，点击捕获选择器，Escape 取消
- **更多菜单**：在默认浏览器中打开 / 打开调试工具
- **空状态**：「粘贴或输入 URL 以打开网页。」
- **URL 校验**：仅支持 http、https、file、about、data 地址，非法输入有提示
- 新开窗口链接自动交给系统默认浏览器

## 运行

```bash
npm install
npm start
```

## 项目结构

```
src/
├── main/       # 主进程：窗口、新窗口策略、openExternal IPC
│   └── main.js
├── preload/    # 预加载：contextBridge 暴露安全 API
│   └── preload.js
└── renderer/   # 渲染进程：布局、面板切换、浏览器面板
    ├── index.html
    ├── styles.css
    └── app.js
```

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+1` | 回到工作台（收起浏览器面板） |
| `Ctrl+2` | 切换浏览器面板 |
| `Ctrl+T` | 新建浏览器标签（面板打开时） |
| `Ctrl+W` | 关闭当前标签（面板打开时） |
| `Escape` | 取消元素选择 / 关闭菜单 |
